# Agent Note: Configurable voice reminder appearance

Status: implemented

## Problem

真机验收位置、文字气泡和固定回退时，每次等待50秒效率低。用户要求紧凑单行，并能设置提示出现时间，保留默认临近提醒。

## Decision

`voiceLimitReminderStartSeconds`表示真实ATVV START后多少秒开始显示，范围0–55，默认50；0立即显示。设置提供原生步进器、“5 秒测试”和“恢复默认”，选择持久化，不隐式复位。单行浮条为192×34，保留倒计时和“松开再按”；上下空间不足仍避到侧面。

出现阈值只控制展示门禁，不能重置真实段的单调起点。5秒出现时显示约剩55秒，最后5秒才变红，60秒仍为接近上限而非伪造硬件结束。早显示也同步提前启用位置跟随；查询仍在倒计时可见期间、单次后台查询完成200ms后复核，到60秒或取消时停止。默认配置仍保持前50秒零扫描。

schema6新增有界整数，schema1–5缺省为50，保留已有能力开关、按键与设备选择；越界值拒绝加载。便携配置保留出现时间但继续关闭能力。预览固定演示最后8秒并持续5秒，独立于真实阈值；结束后恢复仍在进行的真实段展示，不重新开麦。

## Alternatives considered

- 只改测试时钟或假造语音开始：不能验收真实事件与微信位置，使用实际展示阈值。
- 暂时改硬编码再改回：无法让用户自主配置，且需要反复编译与重新关联权限。
- 快速测试自动复位：隐藏的复位时机会干扰连续验收，采用可见的恢复默认按钮。
- 沿用schema5悄悄增加字段：旧应用保存时可能丢失新选择；schema6让旧版保留原数据并明确拒绝未来配置。

## Consequences

用户随后明确授权0.2.13公开推送与保留设置的远端源码升级，实际交付过程单独记录。提前提醒会增加可见期间的窗口复核时长，最长不超过约60秒；用户可恢复50秒。移植、检查与真机边界见[记录](../../../../docs/validation/2026-10-29-compact-reminder-timing.md)。跨屏按用户当前仅单屏的条件跳过；第一轮用户报告右侧，但采集仅录到空闲，不能作为50秒和松开隐藏通过证据。
