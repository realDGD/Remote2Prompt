# Agent Note: Portable configuration files

Status: implemented

## Problem

用户需要备份与迁移按键和语音设置；直接导出偏好 plist 会夹带本机设备身份和窗口状态，直接恢复启用状态也会使陌生配置立即开始监听或接管输入。

## Decision

`ConfigurationTransfer` 使用标明应用格式与版本的 JSON，最大 256 KB。导出保留映射、手势和左右触发键，不包含虚拟麦克风 UID、权限、设备地址或恢复记录。导入验证现有配置 schema、重复绑定和快捷键，再移除设备选择并关闭所有功能开关。

左栏提供原生导入/导出文件面板。导入后显示映射数量和影响，明确确认才整体替换配置；取消和无效文件不写当前设置。导入可在明确确认后修复不可读配置；运行语音或向导时禁用，确认前再次检查。文件读取有上限，不先把任意大文件完整载入内存。

## Alternatives considered

- 直接复制 UserDefaults：无法形成稳定、便携且隐私边界明确的用户文件，未采用。
- 导入后立即恢复所有开关与 UID：跨机器 UID 可能失效且立即触发系统接管，改为重新选择并手动启用。
- 无提示合并：同键同手势的覆盖不明确，使用带摘要的整体替换。

## Consequences

四项核心传输检查覆盖设置往返、左右键保留、能力关闭、设备身份剔除、格式/未来版本、重复绑定、无效快捷键及过大数据。核心 67/67、适配器 59/59 检查、CLT 构建和 bundle 自检通过。原生文件面板与取消/替换的实际交互在本轮集成记录补充；自动检查不证明系统权限可移植。
