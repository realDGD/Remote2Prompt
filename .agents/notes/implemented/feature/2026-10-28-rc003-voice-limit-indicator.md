# Agent Note: RC003 voice limit indicator

Status: implemented

## Problem

本机RC003持续按住时约一分钟结束，同一输入法经键盘触发可持续两分钟。用户需要无声的临近提醒，避免继续说话而未被接收；不以提示代替延长录音。实际限制见[生命周期回归](../../../../docs/validation/2026-10-28-audio-health-lifecycle.md)，设计参考[上游#679](https://github.com/HD838A/remote-mic-app/issues/679)。

## Decision

应用内部接入一个非激活、鼠标穿透的NSPanel。前50秒隐藏，50–55秒橙色，最后5秒红色，使用等宽数字“本段约剩8秒”及“松开再按，接着说”。不闪烁、不播放声音、不发送系统通知，也不自动重开或续租麦克风。两个位置是屏幕底部居中与右下角；在真实开始时选择鼠标所在屏幕，录音期间不追随鼠标，显示器移除时再选可用屏幕。采用visibleFrame和公开全屏辅助/多Space行为，不使用锁屏层级。

`RemoteAudioRuntime`仅以真实ATVV START建立单调时间起点；HID按下、早到音频和重复START不能延长期限。`VoiceLimitIndicator`为纯策略；`VoiceLimitReminderRuntime`仅持有一个可取消deadline，前50秒只安排一次唤醒，最后10秒最多每秒一次。取消、快速重按、旧隐藏回调、睡眠与退出通过代次隔离，睡眠后不复活旧段。ApplicationDelegate强持有配置、映射运行时与提醒，在自身初始化时建立配置/语音订阅，首次打开设置之前即可工作。原先仅在设置onAppear绑定会漏掉只有菜单栏的冷启动，已移除该依赖；关闭设置不会解绑提醒；退出取消任务、订阅、观察者并关闭窗口。

提醒默认关闭。现有HID身份不能可靠区分RC001/RC003，设置明确标为“RC003 临近语音时限时提醒”，由用户选择该估计档案，不宣称自动识别型号。只有启用语音触发与虚拟麦克风的应用遥控器会话才显示；键盘直接拉起输入法不驱动它。设置提供5秒无设备预览；预览不访问音频、权限或系统输入。schema4旧配置缺省关闭提醒，便携导入也关闭提醒，保留位置。

ATVV STOP保留ordinaryReported/timeLimitReported/unspecified分类。上游报告00 08与上限有关，但本机原因码尚未独立核验，因此生产运行时只显示3秒中性“本段语音已结束”。普通松手立即隐藏；主机关闭后的停止确认不能制造到时提示。时钟到60秒仍只显示“已接近单段时限”，不伪造硬件结束。确定性deviceLimit文案仅保留在策略接口，生产没有调用者。

## Alternatives considered

- 仅菜单栏计时容易错过；圆环缺少操作指引；常驻60秒倒计时长期占屏。因此使用临近浮条。
- 系统通知受专注模式影响，声音可能混入识别，闪烁打断说话，因此不用。
- 独立工具轮询日志增加进程和耦合；应用已拥有真实事件，使用内部订阅。
- 自动MIC_EXTEND或重新开麦不能解决上游已报告的限制，还会改变输入事务，不采用。
- 自动按共享VID/PID猜型号不可靠，先使用明确的RC003用户开关。

## Consequences

独立CLT初始`make check`通过；后续`make test`通过85核心/99适配器，更新后的`make build`与bundle/文档/公开边界检查通过。覆盖真实运行时的START起点、重复START、reported结束中性化、主机关闭确认、新旧连接、配置迁移、预览到期、旧deadline、新段、睡眠与退出；不向桌面发送按键。验证细节见[本轮记录](../../../../docs/validation/2026-10-29-voice-limit-indicator.md)。

首次检查时Mac锁屏；用户解锁后已完成隔离设置选项、原生浮条橙/红/自动隐藏及本应用key/main/激活状态检查。实际鼠标点透、全屏、Stage Manager、多屏、浅色及真实RC003仍待验收。已准备隔离硬件的`--smoke-test-reminder`入口，不能把窗口属性和构建通过当作这些场景已通过。STOP没有段标识；旧连接回调已隔离，同一连接新START之后迟到STOP仍需真实控制事件核验，未加入任意忽略窗口。提醒不能保证延长一分钟，也不能挽回已丢失的声音。基础提醒随后已随0.2.8发布，当前安装版与来源见[发布记录](../../../../docs/validation/2026-10-29-source-release.md)。0.2.12新增的胶囊跟随范围见[跟随决策](2026-10-29-follow-wetype-capsule.md)，交付结果另行记录。
