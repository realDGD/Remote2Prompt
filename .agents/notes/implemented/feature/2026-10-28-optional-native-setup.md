# Agent Note: Optional native setup

Status: implemented

## Problem

原向导将六页权限和真实按键门禁串在一起，没有遥控器或无法配合检查时不能完成配置；语音触发与音频设置分离也增加了理解成本。

## Decision

向导采用原生分组表单的准备、配置、检查、确认四步。普通映射、语音触发键、虚拟麦克风和临时输入切换在同一配置页，草稿以当前设置初始化，不在浏览过程中保存。普通按键检查仍要求同一遥控器的两个不同键成对报告；启用语音时再检查语音键。未检查或断连后不显示通过。

“跳过配置”退出且不写草稿；“跳过检查”进入带未检查标记的确认页。保存只应用用户选择，不声称权限、真实音频或输入法通过。未连接或未授权不会阻止用户先保存配置。向导显示期间继续暂停日常映射，退出恢复原有运行方式。

## Alternatives considered

- 保留无线麦不可跳过的向导门禁：参考其准备、设置、检查的任务顺序，但用户明确要求可跳过，因此不采用强制完成策略。
- 跳过时把检查标记为成功：会掩盖真实设备问题，未采用。
- 每一步立即保存：取消不能恢复，采用仅完成时提交的草稿。

## Consequences

独立原生预览实际检查四步布局、所有修饰键符号、变更草稿后跳过配置仍保留原设置、没有设备时检查继续按钮禁用、跳过检查显示明确结果并可保存关闭的配置。CLT Release 构建和 bundle 验证通过。既有真实报告证据策略不变；没有执行人在场的 RC003 或语音输入法验收。
