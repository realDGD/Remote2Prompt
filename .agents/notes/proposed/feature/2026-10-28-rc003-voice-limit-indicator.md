# Agent Note: RC003 voice limit indicator

Status: proposed

## Problem

本机已确认RC003持续按住时约一分钟自动结束，而同一输入法经键盘触发可持续两分钟。用户希望在结束前获得优雅、无声的提示，避免继续说话而未被接收。背景与实测见[生命周期回归](../../../../docs/validation/2026-10-28-audio-health-lifecycle.md)及[上游#679](https://github.com/HD838A/remote-mic-app/issues/679)。

原有传输层把所有0x00停止事件折叠成无参数onStopped。当前框架已保留带分类的停止回调：ordinaryReported、timeLimitReported及unspecified；生产音频运行时暂时忽略分类，保持原释放行为。当前UI计数仍不记录结束原因。不能仅凭墙钟达到60秒就宣称固件已断开。

## Proposal

推荐集成到Remote2Prompt：临近上限时显示一个固定大小的小浮条。前50秒不出现，50–55秒柔和橙色提示，最后5秒柔和红色；文案为“本段约剩8秒”，下方“松开再按，接着说”。数值使用等宽数字，位置和尺寸不随数字变化，不闪烁。正常松手立刻收起；确认时限结束后显示约3秒“已到单段上限 · 松开再按继续”，不自动重开麦克风。

提示本身使用不激活的原生NSPanel和原生内容，鼠标穿透、不抢输入焦点、无声音，不增加屏幕录制或辅助功能权限请求。默认位于当前屏幕底部、输入法语音条上方；在按下时锁定所在屏幕，录音期间不追随鼠标跳屏。使用visibleFrame避让Dock，提供少量位置选择或设置中的位置预览。多桌面/全屏采用公开窗口行为，仍需真机验证，不使用锁屏/屏保层级。

时钟取真实ATVV STREAM START的单调时间，不能从HID按下、按钮点击、首个UI刷新或输入法界面出现开始计时。延迟确认、重复STREAM START不能重置同一段的起点。倒计时是约60秒上限的估计，真正结束以传输/会话事件为准；仅对已确认存在该上限的RC003会话生效，键盘直接触发输入法时不显示。

先补带原因的停止事件接口草案，再接展示策略：普通松手、时限停止、未知停止及链路失效分开。#679的00 08 /00 00 /00 02是报告者的协议观察，本项目尚未独立验证；需要合成检查加本机真实控制事件核对，不存完整控制包或设备身份。未核实时使用中性“语音已结束”，不误标超时。

设置仅保留“临近语音时限时提醒”和少量位置选择，归入遥控器语音输入，关闭虚拟麦克风时隐藏相关设置。推荐随已启用的RC003语音提供提醒；默认值和配置迁移在实施时明确，导入仍保持语音能力关闭。

本轮已准备不接触设备的VoiceLimitIndicator纯策略与五项时序/取消检查，尚未接入生产运行时或窗口。已制作三种可交互视觉方案：临近上限浮条、迷你圆环、菜单栏计时；未接入生产运行时或启用浮窗。具体接口与验收见[实施草案](../../../plans/2026-10-28-voice-limit-indicator.md)。

## Alternatives considered

- 只有菜单栏计时：最克制，但说话时视线通常在输入区，容易错过。适合作为可选低干扰模式。
- 迷你圆环：占用小，但只显示秒数时操作指引不足。适合极简偏好，不作为默认推荐。
- 常驻60秒倒计时：长期占据屏幕；临近时限再出现已经足够。
- 系统通知、提示音、闪烁或红色屏幕边框：通知受专注模式影响，声音可能混入识别，强提示打断说话。
- 独立工具轮询文本日志：增加进程、路径/格式耦合和延迟；现有应用拥有会话事件，优先内部订阅。
- 到60秒就模拟松手再自动重开：上游#355续租/重开实验无效，也会改变用户按键和输入事务，不采用。

## Acceptance criteria

- 49秒不可见，50秒出现，55秒改变紧迫度；正常松手隐藏，不以UI计时假造硬件停止。
- 新旧会话、快速重按、重复开始、迟到停止/Timer、取消、睡眠、退出和配置关闭均不能留下或复活旧浮窗。
- 结束提示的延迟隐藏必须绑定会话代次；旧3秒回调不能隐藏新的倒计时。
- 普通松手、到时、无原因停止、设备断开和权限失效的文案正确；没有自动开麦、系统按键或音频路由副作用。
- 全屏、桌面切换、Stage Manager、多屏拔插、Dock位置、浅/深色、减少动态效果以及首次提示不抢焦点需真实原生验收。
- 独立CLT构建；提示不依赖外部包、音频内容、屏幕录制或额外硬件身份日志。

## Risks

不同固件的停止原因码和开始通知时序可能不同，倒计时只能作为估计。全屏与多屏呈现受macOS窗口层级影响，不能仅凭NSPanel属性存在就宣称所有场景通过。当前0.2.7的一分钟自动结束已记录，提示能减少意外丢话，不承诺延长遥控器单段录音。
