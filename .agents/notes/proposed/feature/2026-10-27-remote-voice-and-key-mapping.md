# Agent Note: 遥控器按键与语音首版

Status: proposed

## Problem

用户希望用遥控器控制 Mac 按键并向现有输入法传输语音，需要可配置映射、左右 Control 语音触发与原生设置。

## Proposal

先支持小米蓝牙遥控器 2 / 2 Pro，通过限定设备的 HID 通道处理普通按键，CoreBluetooth/ATVV 接收语音，经解码和回环设备交给目标输入法。语音会话独立于普通键的手势识别，在排空尾音后成对释放触发键。

当前已实现配置、原生 UI、HID 接入、普通键手势、系统事件发送和设备原生键恢复；RC003 的系统枚举已确认，真实按键端到端验收进行中。CoreBluetooth/ATVV、解码和真实音频路径仍未接入，因此完整语音首版继续保持 proposed。实现顺序见 [路线图](../../../../docs/roadmap.md)。

## Alternatives considered

**从参考项目直接 fork 并删去其他平台。** 可以更快得到硬件代码，但会继承较大的功能、依赖和维护范围；当前选择先独立建立最小工程。未来复用源码需另行处理授权和维护边界。

**内置云端 ASR。** 增加服务费用、网络和隐私路径，超出当前“遥控器作为输入设备”的目标。

## Acceptance criteria

真实遥控器普通键映射可用，语音按住说话、松开后在目标输入框出现识别文本；左右 Control 分别在目标输入法中验证；退出、断连和权限失效不残留按键或设备映射。通过这些验收后才移入 implemented。

## Risks

固件及 HID 行为可能不同，原生按键抑制与虚拟输入识别都需要真机证据。目标输入法可能合并左右修饰键。第三方驱动不可视为可随应用无条件分发的资源。
