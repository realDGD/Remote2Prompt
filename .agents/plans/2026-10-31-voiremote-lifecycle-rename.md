# VoiRemote 生命周期与完整更名 Implementation Plan

**Goal:** 登录后静默运行；设置窗口打开时显示 Dock，关闭时默认隐藏，可选择常驻；统一应用、源码、仓库和项目目录名称。

**Architecture:** 系统登录项采用 SMAppService.mainApp，状态由系统读取；本机 Dock 偏好与登录项不进入便携配置。菜单栏场景常驻，设置窗口按需由 AppKit 承载 SwiftUI，避免登录时先打开再隐藏。完整更名使用 dev.voiremote.app，旧配置只读迁移，旧授权不冒充继承。

**Tech Stack:** macOS 14+、Swift 6、SwiftUI/AppKit、ServiceManagement、独立 CLT、同仓库源码 Cask。

**Spec:** 用户本轮需求及 AGENTS.md；默认关闭登录项和 Dock 常驻。按用户要求精简执行，只做必要测试，不启动子 agent、额外审批或每阶段全套回归。

## Global Constraints

- 不修改映射、语音或系统输入语义；不创建证书、不重置 TCC。
- 仅兼容读取保留旧标识；界面、模块、包、命令、当前文档和远端使用 VoiRemote。
- 保留 Git 历史、旧偏好及历史验证中的实际签名标识，不重写过去验收事实。
- 用户已授权远端仓库和文件夹更名；不另建第二个仓库。

## Review Focus

- 登录启动不得创建设置窗口或抢焦点；首次向导仅在用户打开设置时展示。
- 关闭提醒/授权引导窗口不能误判为设置窗口关闭。
- 系统禁用登录项、注册失败及需要批准时显示真实状态，不伪造开关成功。
- 新配置存在时不得被旧偏好覆盖；旧文件仍可导入。
- 新 Bundle ID 需首次重新授权，之后固定身份；Homebrew 下载归档的前缀随仓库更名变化。
