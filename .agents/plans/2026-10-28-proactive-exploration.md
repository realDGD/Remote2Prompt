# 解锁以外的主动探索队列

用户要求离开期间继续探索。锁屏只阻塞需要原生 UI 的检查，不阻塞源码、模拟运行、官方资料核查和方案整理。每轮推进一个尚未完成的工作包；没有新证据时不重做已完成的全文调研或反复轮询锁屏。

## 工作包与完成条件

- [x] A：使用实际输入运行时加模拟适配器，检查空闲轮询、1000 次会话清理及初始化失败恢复；保留 CLT 探针、结果边界和窄修复提案。见[审查](../../docs/research/2026-10-28-idle-runtime-audit.md)。
- [x] B：核对外部语音工具官方说明的按住/点按、快捷键与麦克风选择，形成[兼容矩阵](../../docs/research/2026-10-28-dictation-compatibility.md)；区别公开能力、配置条件与本项目真机结果，没有安装或登录这些工具。
- [ ] C：将睡眠/锁屏与扫描期限、PCM 入口上界细化为接口、状态、取消和验收方案；用可控时钟/消费者实验验证有价值的不变量，不为凑数再写一套影子产品。
- [ ] D：仅检查第一轮之后新增或影响结论的上游 issue/评论；记录时间、增量和结论。已有 139 项不重扫全文；没有增量也如实结束该包。
- [ ] E：用户解锁后检查安装版原生菜单当前输入、设备菜单和窗口，更新边界及新提交 CI。该包独立等待，不阻塞 A–D。

## 实施边界

本轮以研究、可复现探针和可审阅方案为交付。候选没有自动转为产品需求；保持已装 0.2.0、现有设置及同仓库 tap 的固定源码不变。明确缺陷先记录复现与最小建议，未经选择的功能不直接加入。研究和文档按有意义阶段 commit/push，沿用本任务单一公开仓库的发布授权。

不请求权限、不改真实默认输入、不录音、不重装、不安装驱动、不创建证书、不重置 TCC。模拟使用固定脱敏样例，原始实验留在忽略目录。新增工具与文档按 r2p-check 运行相称检查，不为文档重跑应用构建或安装。

## 额度与续作

每次唤醒和阶段检查账户额度。5 小时剩余不超过 5% 时先保存 `.local/checkpoints/continuation.md`，将同一心跳 `remote2prompt` 改排到工具返回的下次重置之后，再有限收尾；不使用重置券。恢复后回到 30 分钟。状态不变保持安静；队列完成后只保留有价值的实际待验项，全部授权工作完成后删除心跳。
