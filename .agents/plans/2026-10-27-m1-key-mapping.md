# M1 真实遥控器按键映射实施

本轮按已确定的 [产品需求](../../docs/product.md) 直接实施，使用 writing-plans 的分阶段拆分方法；不另启需求审批、强制 TDD 或子 agent。保留 Swift 6、macOS 14、独立 CLT 和默认关闭的设备接管。

## 阶段与提交

- [x] 核心：schema 1 → 2 兼容、任意快捷键、RC001/RC003 report 1 固定样例、单击/双击/长按/重复识别。34 项检查通过后 commit。
- [x] 系统适配：设备限定、按设备 UserKeyMapping 租约及恢复日志、原始 HID 接入、系统动作与左右修饰键事件生成。使用可注入传输验证失败回滚、恢复和事件构造后 commit。
- [ ] 应用接线：授权引导、真实设备状态与活动按键、映射执行、局部快捷键录入、语音键即时成对发送、休眠/退出/权限丢失清理。CLT 构建和 UI 验证后 commit。
- [ ] 验收与文档：更新能力状态、原理和真机矩阵；有硬件时执行真实验收，缺硬件时明确保留未验证项。最后提交记录。

## 关键边界

只匹配 VendorID 0x2717 / ProductID 0x32B8，不用名称模糊接管。使用 Apple TN2450 的设备服务属性映射，校验读回和持久恢复后才开始监听；不按时间窗口吞掉普通键盘事件。语音 HID F5 是独立实时路径，M1 只发送目标输入法触发键，音频解码与回环设备写入留在 M2。

优先验证重复报告、无效报告、缺失设备服务、写入失败、其他软件修改映射、断连、权限丢失、修改设置和休眠后的清理。用户确认设备为 RC003；系统已枚举到“小米蓝牙语音遥控器”、VID/PID 0x2717/0x32B8 和 BLE 键盘接口。枚举不等于按键或语音验收。
