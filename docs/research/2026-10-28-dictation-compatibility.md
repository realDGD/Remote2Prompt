# 外部语音工具的触发与输入条件

核查日期：2026-10-28。只查官方公开资料与本项目 0.2.0 源码，没有安装、登录或改变其他应用配置。以下是待验配置矩阵，**不是 Remote2Prompt 已兼容这些工具的声明**。

## 先区分两个问题

1. 目标工具如何开始和结束录音：保持修饰键、起止各点按一次、双击或混合手势，并不相同。
2. 目标工具从哪里取声音：跟随系统默认、固定某设备或使用自己的优先列表，也不相同。

本项目目前的语音行为是选定 Fn 或左/右 Control、Option、Command，链路就绪后发送按下，遥控器松开并排空后发送释放。语音键不经过普通双击/长按识别。没有起止各发送一次快捷键、任意语音组合键、主动查询第三方录音状态或纯麦克风模式；普通键可录入组合键不表示语音会话也有同样能力。

## 系统输入切换的适用条件

这是结合上述资料与本项目输入事务得出的推断，不是第三方保证：

| 目标工具输入设置 | 本项目切换系统默认输入的作用 | 验收重点 |
| --- | --- | --- |
| 明确跟随系统默认 | 在触发之前选回环并读回，有机会让本次会话使用遥控器；仍须确认工具何时打开/缓存输入 | 开始时实际取到回环；AirPods 抢占后是否重开设备；恢复系统默认是否影响处理中的会话。 |
| 固定所选回环 | 声音来自同一回环；全局切换可能并非必要 | 语音音频链路就绪、未误选另一同名设备；关闭系统接管时也验证正常收音。 |
| 固定实体麦克风 | 本项目改变系统默认通常不足以改变工具选择 | 指引用户在目标工具中选择回环或跟随系统；不自动读取/修改第三方私有配置。 |
| 工具自有优先列表/自动选择 | 由目标工具额外规则决定，不能承诺跟随 | 回环优先、排除规则、设备重连后选择；工具的自动选择与本项目恢复策略是否相互争抢。 |

“写入回环”“系统默认读回正确”“目标工具显示录音”“目标输入框收到文字”是四层证据，分别记录，不能互相替代。

## 快速点按与异常停止为什么要单独验收

VoiceInk Hybrid、Superwhisper 快速点按与 Typeless 的切换流程说明：**只在遥控器松开时释放合成键，未必能结束第三方录音**。实际合成键保持时间还会受链路准备、输入读回、120 ms 尾音和排空影响，不能直接按物理按住时长判断目标分支。尤其不能为“强制结束”在未知状态下再发一次切换键，这可能反而启动录音。

未来点按式触发需要单独定义开始/结束动作、取消语义和能否确认第三方状态；单纯把 keyUp 改成一次点按不够。长时间会话或分段送音也不能让遥控器松手后继续产生声音，更不能据此声称突破固件限制。候选仍见[功能探索](2026-10-28-feature-exploration.md)，尚未接入。
