## 当前行为和边界

原生开关默认关闭。只有明确开启、回环可用、音频已初始化、HID 已接管、权限有效且不在向导中才取得 ready 来源。普通映射可以关闭。实际默认输入、最近请求、最近确认和实体恢复目标分别显示，错误与明确重试入口可见。

写入前按 UID 重查目标并比较来源；接受写入后最多等 1 秒确认，任意两次写入至少间隔 0.5 秒，同一意图三次失败后暂停。初始化前已选虚拟输入不被当作本应用所有；停用后的外部选择保留。正常退出的异步确认预算为 3.5 秒；强制结束、系统 API 阻塞、驱动超窗延迟和非原子读写竞争不属于已验证保证。

真实内建输入 → 遥控器 ready → 回环 → AirPods/USB 抢占 → 回环 → 断连恢复实体、实际权限撤销、音频设备拔出和多遥控器矩阵均未执行。当前生产音频限制单个所有者，多个 ready 的最后断开只通过核心/协调器模拟，不宣称真实多遥控器可用。最新新增代码没有推送，之前公开 CI 的绿色结果不覆盖本轮提交。
