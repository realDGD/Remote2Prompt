# Audio Queue 健康与生命周期回归

本轮保持 Audio Queue、SwiftPM 和独立 Command Line Tools；没有引入证书、驱动、TCC重置或AVAudioEngine迁移。0.2.7源码及同仓库tap已推送到main，并经远端Homebrew源码升级安装；CI和真机结果分别记录，不以安装成功代替硬件验收。

## 按键与界面

“填入常用动作”按用户逐项明细补齐20项：12单击、1双击、7长按，包含电源长按Escape。原需求的19项合计少算了1项，未因此删掉明确指定的动作。音量加减为字符键，方向长按为Command+Fn+方向；已有任意手势保留，调用幂等，不自动开启功能。普通键单击若同时配置双击或长按，需要按既有手势规则等待判定。

用户否定最初按文字长度收缩的原生小按钮。最终维持等宽三列字段，动作左对齐、箭头右置；整块动作入口打开同一菜单，不再把自定义快捷键当独立文本按钮，清除在菜单中，键盘图标直接录入。隔离原生预览已实际检查：填入20项、展开长按快捷键菜单、录入显示已有候选、取消保留、菜单清除只改所选长按，以及录入清空候选后确认只清除所选双击。辅助功能树每格只有一个动作菜单入口。预览使用独立偏好域并关闭硬件，不修改安装版设置。

## 普通检查

- `make check`：78/78核心、89/89 macOS适配器检查通过，不访问真实音频、BLE或HID，不向桌面发送输入。CLT Release应用0.2.7、bundle签名/配置自检、macOS14最低版本与实际SDK27、文档和公开边界检查通过。
- 真实 `LoopbackWriter` 配模拟播放/时钟：空闲停止正常，活跃停止、消费/时钟停滞、转换错误、静音原因和设备丢失有界失败；旧通知、消费与排空回调不影响替换后的输出。
- 真实 `RemoteAudioRuntime` 配模拟传输/目录：静音包与数据中断分开，1/2/4秒最多3次恢复，配置成功不能清预算，健康10秒才恢复预算。覆盖抖动、返回、旧事件、100次快速重按及触发键成对结束。
- 真实音频运行时与真实输入优先运行时配模拟系统：故障及休眠均先释放触发再恢复输入；恢复ready不写系统输入。
- 睡眠检查：活动语音、配置进行中、恢复退避中、重复暂停/唤醒、睡眠中关闭功能、退出后唤醒、睡前计数失效；每个来源必须先报告语音松开，才允许唤醒后按下。

BLE实际查找、连接及能力读取共8秒截止，已移除内部无限重连；该边界为生产源码接入，普通模拟传输不能验证系统蓝牙在各阶段真实回调行为。

## 显式原生音频检查

以下检查已正常退出安装版后独立运行，只提交静音，不采集声音、不发送语音快捷键。

1. `Remote2PromptMacChecks --loopback-stream-smoke --extended --jitter --switch-input`：第一轮120秒，随后两轮各8秒，另30次快速开始/排空/取消；共提交2185600静音样本。发生欠载时序恢复且无迟到排队，健康验证通过，最终默认输入/输出快照恢复。此长测在增加只读静音/零音量检查前执行；未重复长测。
2. `Remote2PromptMacChecks --voice-input-session-smoke`：真实CoreAudio与生产输入事务的3轮确认、实体抢占重选、排空后精确恢复及listener清理通过，系统输出保持原状。
3. 增加只读静音/零音量检查后，`--loopback-stream-smoke --jitter --switch-input`再次通过3轮共384000样本，最终默认输入/输出恢复。未知静音/音量属性保持未知，不写用户音量。
