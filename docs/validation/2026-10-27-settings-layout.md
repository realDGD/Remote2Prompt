# 设置页布局与交互调整

日期：2026-10-27。范围是原生设置和按键编辑。保持三列手势、现有配置格式与默认关闭设置，未改 HID、音频协议或事件发送。

## 本次变化

- 遥控器常驻左侧，右侧编辑区域独立滚动。点击示意图定位到对应行，点击语音键回到顶部；重复点击同一个键也会定位。
- 语音键位于映射页顶端，直接选择 Fn 或左右 Control/Command/Option 并设置独立开关。“音频设置”跳转连接与音频页，该页的语音触发键摘要可返回映射页。
- 普通键按方向导航、常用按键、设备控制三组显示三列。动作菜单直接分组列出，键盘按钮直接录入，已设置的快捷键直接点开重录，清除动作无需另开对话框。
- 快捷键录入显示当前按键与手势，保留候选、清空、取消与确认。
- 增加独立界面预览的配置域与硬件禁用入口，不使用正在运行的应用配置测试映射。实际预览副本使用独立 Bundle ID，不覆盖 Homebrew 应用。

独立 CLT Release 构建、bundle/签名/版本自检通过。原生窗口实际确认左侧遥控器常驻、三列分组、顶部语音卡、点击 TV 后定位、点击语音键返回顶部，以及选择右 Control 后显示更新。
