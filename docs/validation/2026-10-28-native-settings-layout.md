# 原生设置分栏与文案验证

## 变更与根因

保留 SwiftUI `NavigationSplitView`，连接、权限和关于页使用原生分组 Form / Section；权限操作组去掉额外垂直 padding。音频开关改为“启用虚拟麦克风”，说明它把遥控器麦克风声音送入所选虚拟设备供输入法识别，同时启用语音触发，不负责安装设备。没有修改开关绑定或音频行为。

起初标题栏与内容区分隔仍错位；将列宽修饰符放在末尾、换成 Form 及试用紧凑工具栏都没有消除接缝。最终定位到编译 SDK 元数据：当前 CLT 使用 SDK 27.0，应用 Mach-O 却记录 `minos 14.0 / sdk 14.0`。显式设置链接参数后，记录变为 `minos 14.0 / sdk 27.0`，原生窗口外观和贯通分隔线同时恢复。工具链上游对应 [swift-build#1887](https://github.com/swiftlang/swift-build/issues/1887)。临时诊断和工具栏实验已移除。

SDK 版本由使用者的 CLT 自动查询；本机的 27.0 只是本次观察值，不是新安装要求。最低运行要求保持 macOS 14。

## 原生界面检查

使用独立 Bundle ID 的 `.build/ui-preview/Remote2Prompt.app`，配置与安装版隔离，硬件适配器禁用。通过原生 Computer Use 实际检查：

- 权限页：标题栏至内容底部的侧栏分隔线贯通；两个请求按钮下面只保留原生表单内边距，没有原来额外一行留白。
- 折叠、展开侧栏：按钮保持可用，标题和内容由原生容器重排，展开后分隔线仍贯通。
- “窗口 → 缩放”与恢复：两种大小下分隔线保持一致。边缘拖拽未改变窗口尺寸，不把尝试计为通过；尚未覆盖所有窄窗口尺寸。
- 连接页：“启用虚拟麦克风”和完整用途说明可见，功能默认关闭；“去设置”可返回映射页。
- 映射页：遥控器常驻、语音设置置顶、普通按键三列可见，映射和语音触发均关闭。

本轮使用本机 macOS 27.2 暗色外观。未切换系统主题，未请求权限，未连接或播放音频，未写系统输入，未修改安装版设置。没有声称真实遥控器或输入法验收通过。

## 构建与交付边界

已执行：

- `make build`：独立 CLT Release 构建通过，仍有此前已有的 CLT 可选 Frameworks 搜索路径警告。
- `./scripts/verify-app.sh`：Info.plist、版本、签名、自检及 `minos 14.0 / sdk 27.0` 检查通过。
- 对旧安装版运行只读校验：明确拒绝其 `sdk 14.0` 元数据，证明新增检查能捕获原故障；未执行安装版 UI 或硬件入口。
- `bash -n`、`git diff --check`、`make docs-check privacy-check`：通过。未改核心或系统适配器行为，因此没有重复运行硬件无关策略检查。

本轮本地产物和预览不覆盖 `/Applications/Remote2Prompt.app`，也不改远端 Cask 的固定源码版本；安装版仍是此前已验收的 0.2.2 来源。

## 后续：按需显示与统一标题栏

用户进一步指出：连接和权限页的标题栏背景仅覆盖局部，关于页覆盖整个右栏，映射页没有相同效果。连接与权限的 Form 曾被 `.frame(maxWidth: 820)` 限制，现取消整个滚动容器的宽度限制。试用的 `.toolbarBackground(.visible)` 会使映射页固定显示而 Form 页仍自动显示，因此已撤回。依用户最终选择，四页统一使用原生 `.toolbarBackground(.hidden, for: .windowToolbar)`；Form 页在自身应用相同规则，避免其自动偏好覆盖外层设置。不自绘 hover，不改变原生按钮的正常高亮。

虚拟麦克风关闭时保留开关与简短用途，隐藏设备、刷新、连接、测试及触发键摘要；开启才显示。系统输入切换组随音频开启显示，恢复未结束、仍持有输入、存在未确认请求或错误时保留反馈。关闭选项只影响显示，不清空已保存的设备与切换偏好。语音触发关闭时可展开配置键位，开启时直接显示；普通映射保持可编辑。向导的设备和切换选项采用同样条件，关闭音频时不再提示设置输入法麦克风。

最终隔离预览已逐页查看四页标题栏，均没有之前固定的区域背景；对标题栏完整鼠标进入/离开路径仍需人工确认，不能把截图或拖拽尝试视为完整 hover 回归。原生点击还验证：音频开关开/关后相关选项分别出现/消失；关闭语音时展开触发键可见；向导开启虚拟麦克风会显示设备和切换选项，关闭后两者消失，随后“跳过配置”取消草稿。恢复错误反馈仅经代码审查，未注入真实系统故障。
