# 语音键临时输入事务验证

日期：2026-10-27。用户将输入优先语义修订为“空闲跟随系统，按下切到遥控器，松开恢复按下前输入”。本轮保持默认关闭、CLT 和分阶段本地提交，不改现有 Homebrew 安装、TCC、音频驱动或真实默认输入/输出。

## 已接入行为

- ready/连接本身不写系统输入；活动语音开始时才读取默认输入，捕获稳定 UID 快照并切到所选回环。
- 切换经读回确认后才向输入法发送所选触发键，等待期间有界缓存早到 PCM。先松开则取消，晚到确认不补发触发键。
- 按住期间被 AirPods/USB 抢占时重选回环，但恢复目标不变。正常松开保留原有尾音和排空，释放键后恢复精确原输入。
- 其他虚拟/未知输入可以成为精确恢复目标，实体回退仅用于原设备不可用。原设备或回退不存在、恢复失败均不伪报成功。
- 松开后的系统选择被保留；确认窗内旧延迟写入覆盖它时会补偿该选择。快速重按、关闭、取消、断连、权限/音频失效和退出接入同一清理路径。
- ATVV open 不再自行开始或重试语音；原始 HID 语音按下是唯一启动依据。输入准备期间暂停普通映射。

## 已执行自动检查

`make test`：核心 63/63，macOS 适配器 53/53，通过。全部使用合成数据、模拟默认输入系统或注入出口，不向桌面发送实际按键，不切换真实系统默认设备。

新增或修订检查覆盖：空闲设备转移、每次按下重新捕获、按住抢占但不改快照、精确恢复其他虚拟/未知输入、快速重按、延迟恢复中重按、缺少初始默认输入、松开后系统新选择、晚到接管/恢复对该选择的补偿、取消早于确认、确认后才放行触发门禁、链路失效、退出无恢复设备、32000 样本缓存上限和取消清空。

有界失败、通知风暴、读回不生效、写入拒绝、源抢先改变、停止后旧回调、listener 清理、模态退出等待等既有检查继续保留。实现调整期间还发现“停止后的更新覆盖退出未恢复错误”，由无恢复目标的退出检查捕获并修复。

## 验证边界

本机 CLT 编译和原生界面检查单独记录在本轮布局记录中；这不替代真实遥控器音频、微信输入法、首尾音或系统输入切换验收。真实默认输入/输出没有被本轮测试修改；当前运行的安装版保持原样。源码尚未推送，旧 CI 的绿色结果不覆盖这些新提交。

已接受的 CoreAudio 请求无法取消，确认窗外驱动延迟、强制结束和系统崩溃仍不保证恢复。旧在线持续优先方案的结果保存在 [原 M3 记录](2026-10-27-m3.md)，不作为当前行为。
