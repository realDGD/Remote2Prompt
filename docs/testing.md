# 验证

## 自动检查

`make test` 使用 Swift 可执行程序运行核心行为检查，不依赖完整 Xcode 中的 XCTest。任何检查失败都退出非零状态；`make check` 继续构建应用、校验 Info.plist/版本/可执行权限/临时签名，再检查本地文档链接和 Agent Note 状态。

核心用例覆盖默认关闭、旧配置缺省、格式错误/未来版本/重复绑定、映射替换与删除、#435 设备抢占和恢复、多遥控器最后断连、失效回退设备、无设备、左右 Control 键码、成对释放、重复事件、会话中设置变化和取消。

核心检查不发送 CGEvent、不连接蓝牙、不更改默认音频输入。`Remote2PromptMacChecks` 使用模拟 HID 服务、临时恢复文件和注入的事件出口，验证部分写入回滚、读回失配、文件不可写/损坏、跨启动隔离、外部映射修改、新接口、左右 Control 标记、物理修饰键冲突及权限丢失后的释放；不向桌面实际发送输入。

向导检查覆盖两个不同普通键的成对检测、语音独立阶段、旧松开事件、重复报告、其他遥控器来源、断连和重跑后的证据失效，以及补齐导航映射时保留自定义动作。真机还须检查：进入向导暂停日常动作，取消保留配置并恢复之前状态，检测中断后不能继续，完成后才保存。不要用模拟事件替代向导的生产通过条件。

## 应用和安装检查

```sh
make build
./scripts/verify-app.sh
dist/Remote2Prompt.app/Contents/MacOS/Remote2Prompt --smoke-test
make homebrew
# 安装命令见 development.md；安装后运行 brew test
```

UI smoke 只确认真实窗口可见；界面布局、侧栏、滚动、暗色和键盘导航需要目视检查。`--smoke-test-guide` 额外检查拖入帮助面板可见，不打开系统授权、不访问 HID/蓝牙；`--preview-directory` 导出的自身视图缓存不能代替完整原生控件检查。设置保存还需关闭重开核验。Homebrew `test` 只检查已安装应用的无界面自检与版本，不能证明蓝牙、语音或系统权限可用。

普通检查新增覆盖 schema 3 独立语音开关及迁移、ATVV 能力包与合成 IMA/DVI 解码、仅语音模式的源租约恢复和修饰键释放。单独执行 `Remote2PromptMacChecks --loopback-output-smoke` 会向已识别回环设备写入 800 个静音样本并检查排空及默认设备快照；普通 `make test` 不运行它。此硬件检查不读取麦克风，不证明蓝牙音频和目标输入法工作。

## 真机验收矩阵

| 场景 | 预期结果 |
| --- | --- |
| 无遥控器/扫描中/初始化失败 | 不接管系统输入，不显示 ready |
| 优先开关关闭，连接 AirPods | 不修改系统选择 |
| 优先开关打开，遥控器 ready | 选择已明确配置的虚拟输入 |
| ready 期间系统转为 AirPods/USB | 记住实体 UID，恢复虚拟输入 |
| 两只遥控器中一只断开 | 维持虚拟输入 |
| 最后一只断开 | 恢复最近仍可用实体输入 |
| 恢复目标消失/无实体输入 | 选择可用实体候选或保持现状，不写未知 ID |
| 关闭开关/退出/音频失效 | 仅在仍拥有当前虚拟输入时恢复 |
| 写入失败、密集属性通知 | 显示错误，限制重试，无忙循环 |
| 左右 Control、Fn 按住说话 | 目标输入法真实开始与结束，首尾音完整 |
| 说话中切换触发键或断连 | 释放会话最初的键，不粘键 |
| 普通键单击/双击/长按 | 只执行所选动作，原生按键不重复触发 |
| 权限撤销/应用退出 | 停止接管，清理 listener、任务、按键与设备映射 |
| Apple Silicon 与 Intel、macOS 14 与当前版本 | CLT 编译与运行分别记录，不能从单机结果推断 |

M0 结果保存在 [初始化记录](validation/2026-10-27-bootstrap.md)。M1 的设备、权限、按键和 UI 验证边界见 [M1 记录](validation/2026-10-27-m1.md)。最新设置、权限引导和 MiRemoteV 输出结果见 [设置与语音记录](validation/2026-10-27-settings-and-voice.md)。输入法语音、默认输入优先切换与驱动安装仍未验收。
