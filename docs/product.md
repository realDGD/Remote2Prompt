# 产品需求

## 定位与范围

Remote2Prompt 将兼容的蓝牙遥控器变成 Mac 的语音入口和自定义按键设备。首版目标为小米蓝牙遥控器 2 / 2 Pro，面向 macOS，不开发 iOS、Apple Watch 或 Web 客户端。组合动作、统计、记录回眸、订阅、会员、MCP 和云服务均不属于当前范围。

用户已明确：主要使用 Swift；按键可定义与映射；实现参考项目 #435 与 #433；仅用 Command Line Tools 即可编译；通过 Homebrew 从源码安装；设置采用左侧栏的原生界面。以下具体分层、macOS 14 下限和阶段划分是本项目的实施选择，可随需求调整。

## 按键映射

普通键包括方向、确认、返回、主页、菜单、TV、音量与电源，所有键以行显示，单击、双击、长按三列同时编辑。支持常用键、复制/粘贴、应用切换、媒体/音量及任意快捷键；录入先显示候选，清空、取消、确认独立，确认前不修改正式映射。自定义映射默认关闭。

未配置双击或长按的按键应即时响应；配置双击时才等待区分；长按触发后抑制单击。默认只对没有双击/长按映射的方向、退格和音量等动作连发，包含无修饰的自定义方向与退格快捷键；其他动作仅在用户逐键开启后重复。长按动作与连发独立：设置长按后，判定前不执行单击，达到阈值执行长按；开启长按连发后重复长按动作。双击后按住默认仍可转长按；逐键开启双击后按住连发后，第二次按下即执行双击动作，按住继续重复，松开不补发且不再转长按。必须避免物理原生动作与自定义动作同时执行，特别是电源和音量键；无法可靠抑制时，应显示不可用原因并停止对应接管。

语音键不参加普通手势识别。按下立即开始语音会话，松开结束并等待音频排空后释放目标键，避免首字丢失与尾音截断。

## 左右 Control 语音触发（#433）

“启用语音触发”独立于普通映射，默认关闭；只开语音不能接管其他普通键。仅发送触发键时按下/松开即时配对，启用遥控器音频后先确认路由与协议准备；临时切换开启时还需确认系统默认输入，再发送触发并在排空后释放。语音音频默认关闭，目前限制单只兼容遥控器，不混合多来源。

语音触发键包含 Fn、左/右 Control、左/右 Command、左/右 Option。左 Control 对应 macOS 虚拟键码 59，右 Control 为 62；需要同时正确设置通用与设备侧修饰标记。目标输入法必须设置匹配的触发键。该功能指向目标应用发送单独按键，不等于监听本机 Control 作为录音快捷键。

按键事件须成对；重复 begin 不重复按下；结束、取消、断连、权限丢失和退出都要清理。一次会话锁定开始时选定的键，修改设置不能导致释放另一侧按键。多遥控器会话需明确音频源所有权，不能简单混合；当前纯按键策略在最后一位持有者结束前保持首次按下的键。

2026-10-27 核查时，上游 issue 仍为 open，`VoiceKeyMode.swift` 包含 Fn、左右 Command、左右 Option，并将左右 Control 转换为 nil；不能据普通快捷键选择器的 Control 支持认定该 issue 已实现。具体来源见 [参考核查](research/upstream.md)。

## 语音会话临时切换输入（#435 的用户修订语义）

提供“按住语音键时使用遥控器输入”开关，**默认关闭**。开启且遥控器声音、HID 与权限就绪后，也不因连接或音频 ready 修改系统输入。空闲时跟随 macOS 的默认输入变化。

按下语音键时立即读取并锁定当时系统默认输入 UID，将系统默认输入切为用户明确选择、通过驱动 UID/声道验证的 MiRemoteV / BlackHole 回环。只在读回确认后向目标输入法发送触发键；不能将 API 接受请求当作成功。等待期间的少量早到 PCM 在内存中有界保留；取消或溢出不能将旧声音混入下次会话。

按住期间如果 AirPods/USB 等改变默认输入，要重新选择遥控器回环，但不能把后来的输入写成恢复目标。物理松开后保留既有 120 ms 尾音和有界排空，再释放触发键并恢复按下前输入。原设备可以是实体、其他虚拟或未知传输类型，只要仍可作为默认输入；原设备消失才按稳定顺序回退可用实体输入，没有目标则报告未恢复。任何模式都不修改默认输出。

松开后的新系统选择会终止普通恢复重试；若此前已接受的延迟写入仍在确认窗口内生效，则补偿恢复到该新选择，不能用旧按下快照覆盖它。快速重按在旧事务尚未结束时保留原有返回基线，避免把本应用暂时选择的回环当作原输入；旧恢复完成后再按则读取新快照。

开启、关闭、断连、权限/音频失效、向导、休眠和正常退出都须清理输入事务。物理松开或取消后，晚到的切换确认和 ATVV open 不能再次发送触发键。没有按下前快照不能接管；失败需限频并有限重试。真实按下/松开边界立即尝试切换，重试和按住期间的抢占写入至少间隔 0.5 秒；同一意图最多三次失败。正常退出保留 3.5 秒异步恢复预算，强制杀进程无法执行恢复；系统不支持原子比较并写入，也不能撤回超出确认窗才执行的驱动请求。

核心验收：内建麦克风 → 连接遥控器（仍为内建）→ 语音按下（回环）→ 按住时 AirPods 抢占（重新回环，返回目标仍为内建）→ 松开并排空（内建）→ 空闲时系统选择 AirPods（保持 AirPods）→ 再按下/松开（回环后恢复 AirPods）。原设备为其他虚拟输入、设备移除、快速重按、权限/写入失败须另行覆盖。此语义来自用户后续要求，取代上游“在线期间持续优先”的方案。

## 语音链路与分发

首版将遥控器音频解码为 PCM 并写入用户选定的回环设备，由微信输入法等目标应用完成识别；不自行引入 ASR 服务。音频仅保留在内存，不默认录音、不上传。

应用源码构建与虚拟音频驱动安装是独立环节。优先验证已安装的 MiRemoteV / BlackHole；不静默安装驱动、不重启 CoreAudio、不修改其他软件的驱动。是否派生并分发独立驱动，待兼容性和许可调查后决定。

原生设置包含“按键映射”“连接与音频”“权限与隐私”“关于”四页，常驻菜单栏。映射页左侧常驻遥控器示意，点击按键定位右侧对应设置，滚动编辑区时遥控器仍可见。语音键开关和触发键选择固定在右侧顶端；普通键按方向导航、常用按键、设备控制分组，保留三列手势。每格可直接点选动作、打开快捷键录入或清除；连接与音频页集中处理连接和音频，通过链接返回语音键设置。整块遥控器与编辑区下方提供默认收起的高级配置，包含四个全局毫秒参数、跟随所选按键的连发方式及分别恢复默认；不影响语音键即时生命周期。暂不提供组合动作、统计或回眸页面。

侧栏、连接页和菜单栏均可重新运行设置向导。四步为准备、配置、检查、确认，配置包含普通映射、带 ⌃/⌥/⌘ 符号的左右触发键和虚拟麦克风。检查仍要求同一来源两个不同普通键成对报告，启用语音时再检查语音键。向导暂停日常动作，草稿仅完成时保存；“跳过配置”不保存，“跳过检查”明确显示未检查并允许保存。断连或权限失效清除本次检测证据，不能用旧会话或其他来源通过；不宣称音频或输入法成功。

菜单栏只读跟踪当前系统输入，用户明确点选才发起切换，读回确认，语音接管和恢复期间禁用手动切换。遥控器虚拟麦克风是单独的兼容设备选择，不写系统输出。配置以最大 256 KB 的便携 JSON 导入导出，确认替换前不写当前设置；不含本机设备身份和权限，导入后关闭所有能力并重新选择设备。

授权界面显示实际监听能力，不将 IOHIDCheckAccess 的 granted 误写为“已单独授权输入监控”：设备控制授权也可提供监听权限。缺少能力时直接调用公开系统请求；首次或未知状态不立即切换设置窗口，保留系统提示的焦点。系统不再弹窗时提供对应设置及当前应用路径，不用自建说明框代替系统授权。

Homebrew 只保留一个源码型 Cask：下载固定远端源码并用 CLT 编译，将唯一 app 本体移入应用程序，管理启动命令、卸载与可选设置清理。Caskroom 保留受管理链接，构建缓存清理，不安装配套 Formula。安装验收必须通过远端 HTTPS tap，不使用本地源码 checkout。

RC003长段语音有约60秒自动结束的已知上游硬件边界，本机0.2.7长段回归也出现同类现象；不承诺无限长按或自动续开。具体实测与未覆盖范围见[健康与生命周期回归](validation/2026-10-28-audio-health-lifecycle.md)。


“连接与音频”在开启虚拟麦克风后提供默认关闭的“RC003 临近语音时限时提醒”。启用后仅对本应用遥控器语音段，按真实开始估算约60秒，最后10秒显示无声浮条，最后5秒转为红色；普通松开隐藏。0.2.12只在50–60秒倒计时内尝试定位微信语音胶囊，优先放在整个浮动窗口下方或侧面，避免遮住上方未提交文字。依据本机微信输入法3.0.0的实测紧凑轮廓识别；找不到、版本/形状不匹配、目标不唯一或无法安全布局时，使用“固定回退位置”的底部居中或右下角。无设备预览5秒只显示固定位置，不读取微信窗口。

键盘直接触发的输入法不显示，提醒不会延长录音或自动重开；未核验的停止原因只显示中性结束文案。微信在失去输入框焦点后保留文字、再次点击输入框提交或松开后复制到剪贴板的行为由微信管理，本应用不介入。原生全屏/多屏和真实提示仍待验收，见[提醒记录](validation/2026-10-29-voice-limit-indicator.md)与[胶囊跟随边界](validation/2026-10-29-wetype-capsule-follow.md)。

本地后续源码采用紧凑单行，允许语音开始后0–55秒显示，默认50秒；有“5 秒测试”和恢复默认入口。仅改变显示及开始定位的时机，真实段起点、60秒估计上限和最后5秒变红不变。0秒表示立即显示，预览仍独立为5秒。旧配置保留原能力并迁移为50秒，便携导入保留时间但关闭能力。发布与验收边界见[记录](validation/2026-10-29-compact-reminder-timing.md)。
